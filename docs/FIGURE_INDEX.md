# Figure index

The individual experiment figures are generated by `scripts/make_figures.py`.
The WWW three-panel summary is generated by `scripts/make_www_summary_figure.py`.
All figures use only the listed saved CSV files.

| Figure stem | Source data | Purpose |
|---|---|---|
| `architecture_frontier` | `experiment_a_architecture.csv` | Reward, expected claims, volatility, and CVaR as the reuse cap changes |
| `architecture_exposure_breadth` | `experiment_a_architecture.csv` | Endogenous reuse and effective breadth |
| `independence_misspecification` | `experiment_b_misspecification.csv` | Cost of diagonal or estimated covariance models |
| `independence_multiplier_validation` | `experiment_b_misspecification.csv` | Numerical check of `1 + (m-1) rho` |
| `factor_topology_heuristics` | `experiment_c_topology.csv` | Utility losses from transparent diversification heuristics |
| `factor_topology_allocations` | `experiment_c_allocations.csv` | Representative portfolio composition |
| `competition_equilibrium_planner` | `experiment_d_competition.csv` | Equilibrium and planner exposure and CVaR |
| `competition_welfare_gap` | `experiment_d_competition.csv` | Welfare loss from strategic reward capture |
| `solver_scaling` | `experiment_e_solvers.csv` | Runtime scaling across solver families |
| `solver_convergence_trace` | `experiment_e_histories.csv` | Representative convergence traces |
| `risk_measure_entropic` | `experiment_f_risk_robustness.csv` | Mean-variance versus entropic risk |
| `risk_measure_cvar` | `experiment_f_risk_robustness.csv` | Exposure and CVaR under a tail-risk premium |
| `www_empirical_summary` | `experiment_a_architecture.csv`, `experiment_b_misspecification.csv`, `experiment_d_competition.csv` | Three-panel summary used in the WWW paper |
| `contact_sheet` | all generated PNG figures | Visual index for review |

Each stem is written in both PDF and PNG format, except the contact sheet,
which is a PNG review aid.
